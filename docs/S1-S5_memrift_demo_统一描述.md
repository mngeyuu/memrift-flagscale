# S1-S5 统一描述（全覆盖 memrift_demo 权重与激活）

以下表述与 memrift_demo / FlagScale MemRift 实现一致，同时覆盖权重张量与激活张量。

---

**S1**：获取待压缩的模型张量数据，并对所述张量数据进行字段解析，将张量中每个浮点元素拆分为指数字段和符号位-尾数字段；其中，所述张量数据包括模型权重张量或训练过程中产生的激活张量。

**S2**：从所述浮点元素中提取指数字段形成指数流，并对所述指数流进行无损压缩处理，得到压缩指数数据；同时保留符号位与尾数字段数据（以符号位-尾数字段形式一并保留）。

**S3**：记录并保存/记录所述张量的元数据，并根据张量类型采用不同方式保存与使用：

进一步地，对于权重张量：所述元数据包括张量的形状信息、数据类型以及参数名、存储文件名与压缩方案标识；将所述元数据持久化保存至索引文件，用于后续加载与恢复。

进一步地，对于激活张量：所述元数据包括张量的形状信息、步长信息、存储偏移以及数据类型；将所述元数据记录于内存中的占位符对象，供同一次前向与反向中解压重组使用，不进行持久化存储。

**S4**：将步骤 S2 得到的压缩指数数据、未压缩的符号位-尾数字段数据以及步骤 S3 记录的元数据组合形成压缩张量对象，并将所述压缩张量对象存储至存储介质中。

在本实施例中，所述存储介质可以为主存、显存、磁盘或固态存储设备等可用于数据保存的介质。压缩张量对象作为原始张量的替代存储形式，可用于模型检查点保存、模型参数缓存以及训练过程中激活数据的暂存等场景。其中，所述压缩后的指数流数据存储于第一存储介质，所述符号位-尾数字段数据存储于第二存储介质，所述第一存储介质与所述第二存储介质位于不同的存储层级。

进一步地，对于权重张量：所述压缩张量对象持久化存储至磁盘（或等效持久化介质），索引元数据保存于索引文件中，压缩指数与符号位-尾数可分别存于磁盘文件，加载时符号位-尾数可置于显存；对于激活张量：所述压缩张量对象仅于当次训练步内在内存中替代原始激活，压缩指数位于主存、符号位-尾数位于显存，反向计算完成后即释放，不进行持久化存储。

进一步地，在大语言模型微调过程中，当系统需要保存模型参数或暂存中间激活数据时，可将原始张量转换为压缩张量对象并进行相应存储。由于压缩对象中的指数子流已经过无损压缩处理，整体存储开销显著降低，同时保留张量恢复所需的关键信息；其中权重可持久化保存供后续加载，激活仅于当前训练步内暂存并在反向完成后释放。

**S5**：在需要恢复张量数据时，对所述压缩指数数据进行解压处理，并将解压后的指数数据与所述符号位-尾数字段数据进行重组，得到与原始张量在数值和形状上等价的张量。其中，对于权重张量，根据元数据中的形状按 C 连续存储布局恢复；对于激活张量，根据占位符对象中的步长与存储偏移恢复，得到与原始张量在布局上一致的张量。
