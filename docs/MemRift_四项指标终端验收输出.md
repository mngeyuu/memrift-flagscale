# MemRift 四项性能指标终端验收输出说明

本文档统一说明“大模型压缩系统”四项性能指标的测试命令、最终终端显示、计算公式、验收阈值和判定方式。

四项指标分别为：

1. 模型压缩比例；
2. Loss 损失；
3. 训练最大上下文长度；
4. 推理模型载入时间。

每项指标均通过独立脚本启动。脚本执行过程中可以输出训练或测试日志，但在脚本退出前，终端最后一屏统一显示以下信息：

- 软件名称；
- 测试模型；
- 模型类别；
- 测试场景；
- 测试口径；
- 生成时间；
- 基线实测值；
- MemRift 实测值；
- 收益或损耗计算公式；
- 验收要求；
- `PASS`/`FAIL` 最终判定；
- 验收证据 JSON 路径。

> 说明：下列数值用于展示终端格式，不代表尚未运行的测试已经通过。正式验收以每次脚本实际生成的数值和 `result.json` 为准。

## 一、模型与类别对应关系

| 测试模型 | 模型标识 | 验收模型类别 |
|---|---|---|
| Qwen3-8B | `qwen3_8b` | 业界主流模型 |
| LLaMA-3.1-8B | `llama8b` | 业界主流模型 |
| Aquila2-7B | `aquila` | 智源自研模型 |

验收要求“分别在业界主流模型和智源自研模型上测试”时，应至少完成：

- Qwen3-8B 或 LLaMA-3.1-8B 中的一套业界主流模型测试；
- Aquila2-7B 的一套智源自研模型测试。

以下示例以 Qwen3-8B 为主。将命令中的 `qwen3_8b` 替换为 `llama8b` 或 `aquila`，即可运行对应模型的同项测试。

## 二、模型压缩比例

### 2.1 测试命令

```bash
cd /share/project/mengyc/code/memrift-flagscale

CUDA_VISIBLE_DEVICES=0 \
  bash scripts/metrics/qwen3_8b/compression_ratio.sh
```

### 2.2 测试口径

- 基线值 `S0`：BF16 模型参数参考大小；
- 优化值 `S1`：MemRift 压缩目录中文件的总大小；
- 压缩收益采用“存储节省率”；
- 两边必须使用统一的模型大小统计范围。

计算公式：

```text
存储节省率 = (S0 - S1) / S0 × 100%
```

验收要求：

```text
存储节省率 >= 30%
```

## 三、Loss 损失

### 3.1 测试命令

```bash
cd /share/project/mengyc/code/memrift-flagscale

CUDA_VISIBLE_DEVICES=0 \
  bash scripts/metrics/qwen3_8b/accuracy_loss.sh
```

### 3.2 测试口径

- 基线值 `L0`：Pure LoRA 训练日志中的最终 `lm loss`；
- 优化值 `L1`：MemRift 权重压缩+LoRA 训练日志中的最终 `lm loss`；
- 两边使用相同模型、数据、batch size、训练步数和其他关键配置；
- 此项关闭激活压缩，避免把上下文显存优化项混入模型权重精度损失口径；
- Loss 指标不使用 GSM8K/HellaSwag accuracy；
- Loss 下降得到负的相对损耗，仍然判定为通过。

计算公式：

```text
相对 Loss 损耗 = (L1 - L0) / L0 × 100%
```

验收要求：

```text
相对 Loss 损耗 <= 1%
```

## 四、训练最大上下文长度

### 4.1 测试命令

```bash
cd /share/project/mengyc/code/memrift-flagscale

CUDA_VISIBLE_DEVICES=0 \
  bash scripts/metrics/qwen3_8b/train_context_gain.sh
```

### 4.2 测试口径

- 基线值 `L0`：Pure LoRA 在固定硬件和配置下的最大可运行训练上下文；
- 优化值 `L1`：MemRift+LoRA 在相同硬件和配置下的最大可运行训练上下文；
- 固定 GPU、模型、batch size、训练步数和其他关键配置；
- 训练成功要求进程正常退出、日志中不存在错误/OOM，并且产生有效 `lm loss`。

计算公式：

```text
上下文长度收益 = (L1 - L0) / L0 × 100%
```

验收要求：

```text
L1 >= 1.2 × L0
```

等价于：

```text
上下文长度收益 >= 20%
```

## 五、推理模型载入时间

### 5.1 测试命令

```bash
cd /share/project/mengyc/code/memrift-flagscale

CUDA_VISIBLE_DEVICES=0 \
  bash scripts/metrics/qwen3_8b/load_time_reduction.sh
```

### 5.2 测试口径

- 基线值 `T0`：原始模型权重文件的磁盘读取时间；
- 优化值 `T1`：MemRift 压缩权重文件的磁盘读取时间；
- 两边使用相同文件读取实现和计时边界；
- 正式验收应保持存储设备和 OS 缓存条件一致；
- 当前脚本不包含模型实例化和首轮前向。

计算公式：

```text
载入时间下降比例 = (T0 - T1) / T0 × 100%
```

验收要求：

```text
T1 <= 0.7 × T0
```

等价于：

```text
载入时间下降比例 >= 30%
```

## 八、验收结论汇总

| 指标 | 计算公式 | 验收要求 |
|---|---|---|
| 模型压缩比例 | `(S0 - S1) / S0 × 100%` | 存储节省率 `>= 30%` |
| Loss 损失 | `(L1 - L0) / L0 × 100%` | 相对 Loss 损耗 `<= 1%` |
| 训练最大上下文长度 | `(L1 - L0) / L0 × 100%` | `L1 >= 1.2 × L0` |
| 推理模型载入时间 | `(T0 - T1) / T0 × 100%` | `T1 <= 0.7 × T0` |

单项通过时，终端最后显示：

```text
本项最终判定：符合指标 (PASS)
```

单项不通过时，终端最后显示：

```text
本项最终判定：不符合指标 (FAIL)
```
